# ESP32 Firmware

Firmware for the Smart Room Digital Twin project.

## Hardware
- ESP32
- DHT11 temperature and humidity sensor
- Photoresistor (LDR)
- LM393 sound sensor module
- HC-SR501 PIR motion sensor
- Red LED

## Responsibilities
- Read physical sensor data
- Publish measurements via MQTT
- Receive remote LED control commands
